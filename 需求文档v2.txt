# 芙蓉出海服务总部港 - 需求文档v2

## 1. 项目概述
芙蓉出海服务总部港（FLO Overseas Service Station）是聚焦中非经贸领域、为企业出海非洲提供全链条服务的专业平台，需搭建一套包含企业官网和单用户管理后台的系统。

**核心目标**：
- 打造极致精致的企业级官网
- 支持完整的中英文双语国际化
- 提供丰富的企业服务功能
- 开发单用户管理后台
- 集成AI智能体功能

## 2. 网站结构设计

### 2.1 整体架构
```
flocaetp-project/            # 项目根目录
├── flocaetp-website/        # 前端静态网站（HTML+CSS+JavaScript）
│   ├── public/              # 静态资源（图片、logo）
│   ├── index.html           # 主页面
│   ├── styles.css           # 样式文件
│   └── scripts.js           # 交互脚本
├── flocaetp-server/         # 后端服务（Express+SQLite）
│   ├── index.js             # 服务入口
│   └── flocaetp.db          # SQLite数据库
├── 需求文档v2.txt           # 需求文档
└── README.md               # 项目说明
```

### 2.2 前端页面结构
- **Header**：品牌logo、导航菜单、中英文切换
- **Hero区**：核心价值主张、企业定位
- **服务流程**：9大出海服务环节
- **十大服务中心**：企业服务、商旅考察等
- **政策新闻**：动态新闻展示
- **入驻企业**：合作伙伴展示
- **咨询表单**：在线客服咨询
- **Footer**：联系信息、版权声明

## 5. API接口设计

### 5.1 前端请求封装
```javascript
const api = {
  baseURL: '/api',
  // 核心接口
  submitConsult: '/consult',
  getNews: '/news',
  getEnterprises: '/enterprises',
  aiGenerateNews: '/ai/generate-news'
}
```

### 5.2 核心接口列表
| 接口路径               | 方法 | 功能                     | 鉴权 |
|------------------------|------|--------------------------|------|
| /api/consult           | POST | 提交咨询                 | 否   |
| /api/news              | GET  | 获取新闻                 | 否   |
| /api/enterprises       | GET  | 获取企业                 | 否   |
| /api/ai/generate-news  | POST | AI生成新闻               | 是   |
| /api/login             | POST | 管理员登录               | 否   |
